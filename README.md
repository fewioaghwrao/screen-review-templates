# 画面改修向け確認観点テンプレート集

画面改修案件における **確認観点整理・横断確認・影響範囲整理** を行うためのテンプレート集です。

CSS差し替え、文言修正、レイアウト変更、共通部品改修など、**複数画面にまたがるUI変更案件** を想定し、確認漏れを減らしながら進めるための実務向けフォーマット・ガイド・記入例を整理しています。

---

## 概要

本リポジトリは、画面改修案件で使用できる以下のような資料をまとめたテンプレート集です。

- 横断確認観点表
- 画面一覧テンプレート
- 確認の進め方ガイド
- 横断確認の考え方ガイド
- 代表画面の選び方ガイド
- 既存画面読解マニュアル（Razor Pages題材）
- 不具合切り分けメモ
- 画面別確認メモテンプレート
-  一覧 / 詳細 / 入力 / 確認 / モーダル画面向け観点テンプレート
- 共通レイアウト改修時の観点集
- CSS差し替え案件の記入例
- 画面改修案件の観点整理サンプル
- 不具合切り分けメモの運用ルール

実装コードではなく、**画面改修案件を安全に進めるための整理資料・確認資料** を主な対象としています。

## テンプレート一覧

### 1. 横断確認観点表

複数画面を対象に、共通観点を横並びで整理するためのテンプレートです。

主な用途：

- 共通部品の影響確認
- 画面横断での確認漏れ防止
- 優先度を付けた確認計画

### 2. 画面一覧テンプレ

対象画面を棚卸しし、画面種別・重要度・共通部品有無などを整理するためのテンプレートです。

主な用途：

- 対象範囲の見える化
- 代表画面の選定
- 優先順位付け

### 3. 不具合切り分けメモ

不具合発生時に、共通部品起因か個別画面起因かを整理するためのテンプレートです。

主な用途：

- 再確認範囲の判断
- 波及確認の記録
- 修正依頼時の情報整理

### 4. 確認の進め方ガイド

画面改修案件で、どの順で確認を進めるかを整理したガイドです。

主な用途：

- 初動の進め方整理
- 横断確認の手順化
- テスト観点作成前の整理

### 5. 横断確認の考え方ガイド

横断確認が必要になる背景と、画面単位確認との使い分けを整理したガイドです。

主な用途：

- 横断確認の考え方整理
- 共通観点と個別観点の切り分け
- 実務での使い分けの明確化

### 6. 代表画面の選び方ガイド

横断確認の起点となる代表画面を、どの観点で選ぶかを整理したガイドです。

主な用途：

- 代表画面候補の選定
- 重要度 / 利用頻度 / 変更影響の整理
- 横展開しやすい確認順の検討

### 7. 画面別確認メモテンプレ

横断確認観点表で拾いきれない、画面固有の確認事項や気付きを補完するためのテンプレートです。

主な用途：

- 画面固有仕様の確認
- 個別不具合の記録
- 横展開確認の補助

### 8. 画面種別別テンプレート

一覧画面、詳細画面、入力画面、確認画面、モーダル画面など、画面種別ごとに確認しやすい観点を整理したテンプレート群です。

主な用途：

- 画面種別ごとの確認観点整理
- 汎用テンプレからの詳細化
- 実案件への落とし込み補助

### 9. 共通レイアウト改修時の観点集

共通ヘッダー、メニュー、コンテンツ領域、フッター、固定要素など、複数画面の土台部分に影響する改修向けの観点集です。

主な用途：

- 共通レイアウト変更時の影響確認
- 画面横断の波及確認
- 代表画面選定時の補助

### 10. サンプル / 記入例

テンプレートを実際にどう使うかを示すためのサンプルです。

主な用途：

- 記入イメージの共有
- 観点整理方法の見本
- 初回利用時の参考資料

### 11. 不具合切り分けメモ運用ルール

不具合切り分けメモの対応状況や記入ルールを揃えるための補助ガイドです。

主な用途：

- 状況管理の表記ゆれ防止
- 修正済 / 完了 の使い分け
- 進捗共有の整理

### 12. 既存画面読解マニュアル

既存画面を改修する前に、どこをどう読めばよいかを整理したガイドです。
Razor Pages を題材にしつつ、既存Web画面読解の基本手順、確認観点、影響範囲整理、詳細設計書へのつなげ方をまとめています。

主な用途：

- 改修前の調査手順整理
- 共通部品 / 画面固有部品の切り分け
- 影響範囲整理の前段作業
- 詳細設計書や確認観点作成の前提整理

## 基本的な進め方

画面改修案件では、以下の流れを基本としています。

1. 対象画面を一覧化する
2. 共通部品と個別部品を整理する
3. 横断確認観点表の初版を作成する
4. 代表画面で先に確認し、観点を調整する
5. 優先度の高い画面から横展開する
6. 個別画面固有の観点を追加する
7. 不具合発生時は波及範囲を切り分ける

## このリポジトリの位置づけ

このリポジトリは、本番移行資料そのものではなく、**確認観点の整理・進め方のテンプレート化** を目的としたものです。

そのため、以下のような資料とは役割が異なります。

- 本番移行手順書
- 差分資材一覧
- 反映後確認チェックリスト
- 切り戻し手順書

本リポジトリは、それらの前段階である **「どう整理して、どう確認するか」** を支援する位置づけです。
