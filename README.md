# Screen Review Templates

画面改修案件における **確認観点整理・横断確認・影響範囲整理** を行うためのテンプレート集です。

CSS差し替え、文言修正、レイアウト変更、共通部品改修など、**複数画面にまたがるUI変更案件** を想定し、確認漏れを減らしながら進めるための実務向けフォーマットを整理しています。

---

## 概要

本リポジトリは、画面改修案件で使用できる以下のような資料をまとめたテンプレート集です。

- 横断確認観点表
- 画面一覧テンプレート
- 確認の進め方メモ
- 不具合切り分けメモ
- 画面種別ごとの観点整理サンプル

実装コードではなく、**画面改修案件を安全に進めるための整理資料・確認資料** を主な対象としています。

---

## 想定する利用シーン

- CSS差し替え案件
- 共通レイアウト変更案件
- ボタン / 入力欄 / テーブルなど共通部品の見直し

## テンプレート一覧

### 1. 横断確認観点表

複数画面を対象に、共通観点を横並びで整理するためのテンプレートです。

主な用途：

- 共通部品の影響確認
- 画面横断での確認漏れ防止
- 優先度を付けた確認計画

### 2. 画面一覧テンプレ

対象画面を棚卸しし、画面種別・重要度・共通部品有無などを整理するためのテンプレートです。

主な用途：

- 対象範囲の見える化
- 代表画面の選定
- 優先順位付け

### 3. 不具合切り分けメモ

不具合発生時に、共通部品起因か個別画面起因かを整理するためのテンプレートです。

主な用途：

- 再確認範囲の判断
- 波及確認の記録
- 修正依頼時の情報整理

### 4. 確認の進め方ガイド

画面改修案件で、どの順で確認を進めるかを整理したガイドです。

主な用途：

- 初動の進め方整理
- 横断確認の手順化
- テスト観点作成前の整理

---

## 基本的な進め方

画面改修案件では、以下の流れを基本としています。

1. 対象画面を一覧化する
2. 共通部品と個別部品を整理する
3. 横断確認観点表の初版を作成する
4. 代表画面で先に確認し、観点を調整する
5. 優先度の高い画面から横展開する
6. 個別画面固有の観点を追加する
7. 不具合発生時は波及範囲を切り分ける

## このリポジトリの位置づけ

このリポジトリは、本番移行資料そのものではなく、**確認観点の整理・進め方のテンプレート化** を目的としたものです。

そのため、以下のような資料とは役割が異なります。

- 本番移行手順書
- 差分資材一覧
- 反映後確認チェックリスト
- 切り戻し手順書

本リポジトリは、それらの前段階である **「どう整理して、どう確認するか」** を支援する位置づけです。
